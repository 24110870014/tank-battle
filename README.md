# 坦克大战（HTML5）

一个纯 HTML + Canvas + JavaScript 实现的经典坦克大战小游戏，**单文件、零依赖**，双击 `index.html` 即可在浏览器中运行。

## 玩法

- 操控我方绿色坦克，消灭不断来袭的敌方坦克。
- **守住底部中央的基地（金色星星）**——基地被击毁则游戏结束。
- 每关消灭所有敌人后自动进入下一关，敌人会越来越多、越来越强。

## 操作

| 按键 | 功能 |
| --- | --- |
| `W` / `A` / `S` / `D` 或方向键 | 移动 |
| `空格` 或 `J` | 射击 |
| `P` | 暂停 / 继续 |
| `R`（游戏结束时） | 重新开始 |

## 游戏元素

- **砖墙**：可被子弹击毁。
- **钢墙**：不可破坏。
- **水域**：坦克无法通行，但子弹可以飞过。
- **树丛**：坦克可躲藏其中（会被树冠遮挡）。

## 道具

- ★ **火力升级**：子弹更快、射速更高（最多 3 级）。
- 🛡 **无敌护盾**：短时间内无敌。
- ❤ **增加生命**：生命 +1。
- 💣 **全屏炸弹**：消灭当前场上所有敌人。

## 运行

直接用浏览器打开 `index.html`，或启动一个本地服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```
